# Commitchell

Databricks demos and reference implementations by Mitchell Grewer.

| Project | What it is |
|---|---|
| [genie-agents-in-production](genie-agents-in-production/) | CI/CD for Genie agents with Databricks Asset Bundles (agent, SQL warehouse, tables and metric views promoted dev to prod), plus fleet observability: continuous benchmarks, feedback harvesting, alerts, and a fleet health dashboard. |

Each project folder has its own README with setup and cleanup steps. Nothing here contains customer data; set your own catalog, schema, and warehouse values per project.
